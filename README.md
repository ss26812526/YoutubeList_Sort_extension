# YT Playlist Sorter

繁體中文 | [English](README.en.md)

Chrome / Edge 通用的瀏覽器擴充功能，改善 YouTube 播放清單的歌曲排序體驗。

## 解決的問題

1. **拖曳排序後頁面重新載入** — YouTube 原生拖曳排序後會刷新播放清單，導致捲動位置跳掉
2. **拖曳手柄太小** — 原生的 ≡ 拖曳手柄難以操作
3. **長清單難以找到目標位置** — 頁面一次只載入約 100 首，要知道想放的位置編號，得先捲動到那附近

## 功能

- 每首歌旁邊顯示 ↕ 按鈕，點擊後輸入目標位置即可移動
- 支援「移到最前面」快捷操作
- **多選移動**：在頁面勾選，或按畫面上方的「☑ 多選」從完整清單勾選多部影片，一次移到指定位置；移動後依原本的先後順序相連排列。操作列使用與 YouTube 主題相反的高對比配色，位置可在設定面板改為畫面上方或下方
- **從完整清單選擇位置**：彈出視窗列出整份播放清單（編號、縮圖、歌名、頻道），可用歌名、頻道或編號搜尋，點選即填入目標位置；不受頁面只載入前 100 首的限制
- **移動進度顯示**：面板顯示「取得完整播放清單」→「寫入 YouTube」的步驟狀態，失敗時標示出錯的步驟
- **移動動畫**：起點與終點都在畫面內時，歌曲會滑到新位置、其他歌曲順勢讓位；距離較遠時自動捲動到新位置；完成後閃爍外框標示落點。系統開啟「減少動態效果」時不播放動畫
- 移動後不刷新頁面，並同步更新 YouTube 內部的清單資料，之後仍可正常使用原生拖曳排序
- 每首歌右上角顯示排序編號，移動後即時更新（頁面底部的「推薦影片」不會被編號）
- 自動適配 YouTube 深色 / 淺色主題
- **設定面板**：點工具列上的擴充功能圖示，可開關擴充功能、開關排序編號、設定多選操作列位置（上方／下方），並切換介面語言（自動跟隨 YouTube／繁體中文／English），變更立即生效

## 安裝

1. 下載或 clone 此專案
2. 開啟瀏覽器擴充功能頁面（`chrome://extensions` 或 `edge://extensions`）
3. 開啟「開發人員模式」
4. 點擊「載入未封裝項目」，選擇此專案資料夾

更新程式後，需在擴充功能頁面按「重新載入」，並重新整理已開啟的 YouTube 分頁才會生效（舊分頁仍執行舊版程式）。

## 使用方式

1. 開啟你自己的 YouTube 播放清單頁面
2. 每首歌右側會出現 ↕ 按鈕
3. 點擊按鈕，輸入目標位置；或按「📋 從完整清單選擇位置」，在清單中搜尋並點選想放的位置
4. 按「確認」（或 Enter），歌曲會移動到指定位置，頁面不會重新載入

## 技術架構

- **Manifest V3** — 相容 Chrome 與 Edge
- **Content Script (`world: "MAIN"`)** — 存取 `window.ytcfg` 取得 API 認證資訊
- **設定橋接（`bridge.js`）** — 在隔離環境讀取 `chrome.storage` 的設定，轉交給主程式；只需要 `storage` 權限
- **YouTube InnerTube API** — 透過 `/youtubei/v1/browse` 取得完整清單，`/youtubei/v1/browse/edit_playlist` 執行移動操作
- **SAPISIDHASH 認證** — SHA-1 雜湊產生認證標頭
- **Polymer 資料同步** — 移動後以 `splice` 更新 YouTube 內部清單資料，畫面隨之重繪
- **FLIP 動畫** — 以 CSS `transform` 播放移動動畫，只處理畫面內的元素

## 限制

- 僅適用於自己擁有的播放清單（需要有編輯權限）
- 清單設有「已隱藏無法播放的影片」時，擴充功能只計算可見的影片，編號與總數會比標題顯示的少
- 不建議在多個分頁同時編輯同一份清單；另一個分頁的畫面不會自動更新，重新整理即可
- YouTube API 格式與頁面結構可能隨時變動，需要對應更新
